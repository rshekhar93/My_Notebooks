Module 1: The Interface & Admin Basics

Ground Zero: Navigation & Setup

Before analyzing data, you must master the environment. The Excel grid is your canvas.

1. The Anatomy

  • Workbook: The file itself (like a notebook).
  • Worksheet: The tabs at the bottom (pages in the notebook).
  • Ribbon: The toolbar at the top (Home, Insert, Data tabs).
  • Address Bar: Shows A1, C5 etc.
Analyst Tip: Never merge cells in a raw dataset. Merged cells break Python libraries like Pandas and SQL imports. Use "Center Across Selection" instead.

2. Admin Tasks

  • Freeze Panes: Keep your headers visible while scrolling (View > Freeze Panes).
  • Printing: Set Print Area and "Fit to 1 Page" to avoid printing 100 empty columns.
  • Formatting: Use Ctrl+1 for the Format Cells dialog (Number, Currency, Date).

Module 2: Data Entry & Hygiene

Clean Data = Accurate Models

Garbage In, Garbage Out. As an analyst, 80% of your time is cleaning data.

1. The "Customers" Dataset

Imagine you have raw data like: Doe, John | 2023-01-01 | 4500

2. Essential Tools

  • Flash Fill (Ctrl+E): The AI of Excel. Detects patterns and auto-fills data. Great for splitting names or formatting emails.
  • Text to Columns: (Data Tab) Split a single column into two based on a delimiter (comma, space).
  • Remove Duplicates: (Data Tab > Data Tools) Critical for ensuring unique records.
Analyst Tip: Dates in Excel are actually numbers (serial numbers). If you see `44927` instead of a date, just change the Format to "Short Date".

3. Keyboard Shortcuts (Speed is Key)

  • Ctrl + Arrow: Jump to the edge of data.
  • Ctrl + Shift + Arrow: Select data to the edge.
  • Ctrl + ;: Insert today's date (static).

Module 3: Essential Formulas for Analysts

Logic & Lookups

This is the core of Excel analysis. We move from data entry to data intelligence.

1. The IF Function

Logic: =IF(Condition, Value_if_True, Value_if_False)

=IF(B2>1000, "High Value", "Standard")

2. VLOOKUP (Vertical Lookup)

Used to join data from two tables (like a SQL JOIN). You have an ID, you want the Name associated with it.

1. Lookup Value A2
What ID are you searching for?
2. Table Array D:G
Where is the data?
3. Col Index 3
Which column to return?
4. Range Lookup 0
Exact Match (Always use 0/FALSE)

Syntax: =VLOOKUP(A2, D:G, 3, 0)

3. Aggregates

  • =COUNTIF(Range, Criteria): Count how many sales were > $500.
  • =SUMIF(Range, Criteria, Sum_Range): Sum sales ONLY for "Region A".

Module 4: Data Visualization & Statistics

Visualizing Insights

Data visualization helps identify outliers and trends instantly.

1. Descriptive Statistics

  • =AVERAGE(range): The mean.
  • =MEDIAN(range): The middle value (often better than average for salaries/sales).
  • =STDEV.S(range): Standard Deviation (how spread out the data is).

2. Essential Charts

Analyst Tip: Select your data, then press Alt + F1 to instantly insert a default column chart.
  • Histogram: Best for checking distribution (e.g., age groups of customers).
  • Scatter Plot: Best for correlation (e.g., Ad Spend vs. Sales).
  • Box & Whisker: Best for spotting outliers.
Task: Select your Sales column. Go to Insert > Recommended Charts. Pick a Column Chart. Add a Trendline (Right click data bar > Add Trendline).

Module 5: Advanced Data Crunching

The Power of Pivot Tables

Pivot Tables are the "Group By" of Excel. They allow you to summarize 100,000 rows in seconds.

1. Creating a Pivot

Insert > PivotTable. Drag fields into the 4 quadrants:

  • Rows: Categories (e.g., Region, Product).
  • Values: Metrics (e.g., Sum of Sales, Count of Customers).
  • Columns: Sub-groups (e.g., Year).
  • Filters: High-level screening.

2. Slicers

Slicers are visual buttons that filter your Pivot Table. They are user-friendly and great for dashboards.

Analyst Tip: Always format your raw data as a "Table" (Ctrl+T) before creating a Pivot Table. This ensures new data added later is automatically included when you click "Refresh".
