Module 3: The Analyst's Toolkit (Functions)

1. VLOOKUP / XLOOKUP (Merging Data)

Used to bring data from one table into another based on a common ID.

=VLOOKUP( What_to_look_for, Where_to_look, Which_column_to_return, False/0 )
Python/Pandas Analogy:
VLOOKUP is exactly like a Left Join in SQL or pd.merge(df1, df2, on='ID', how='left') in Python.

2. Logic (IF Statements)

Creating new categories based on data.

=IF( Sales > 1000, "High Performance", "Low Performance" )

Hands-on Capstone Project: "The Retail Analyst"

Objective: You have been given a raw sales dump (CSV). Your manager needs a report on profitability by region.
  1. Import & Clean:
    • Remove duplicates based on "Order ID".
    • Fix "Customer Name" formatting using PROPER.
    • Fill blank "Region" cells with "Unknown".
  2. Analyze:
    • Create a new column Profit_Flag: If Profit < 0, "Loss", else "Profit".
    • Use VLOOKUP to add a "Manager Name" column from the secondary table.
  3. Visualize:
    • Insert a Pivot Table: Rows = Manager, Values = Sum of Sales.
    • Create a Bar Chart showing top 5 Managers.
    • Use Conditional Formatting to highlight any transaction with a "Loss".
